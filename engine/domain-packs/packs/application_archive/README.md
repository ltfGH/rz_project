# 申请与归档领域包

`application_archive@1.0.0` 提供多轮顺序审批、只追加审批记录、托管文件版本、申请归档、证照续期和软件内到期提醒，能力为 `application.core` 与 `archive.core`。

审批支持 1–3 级固定角色。驳回或撤回后须先修订为草稿，再提交新轮次；旧节点和审批记录永久保留。最终批准处理器只能通过允许列表命令总线调用其他领域命令，处理器失败时审批与桥接写入同一 SQLite 事务回滚。

文件导入采用 `staged -> ready/failed`：主进程文件选择器复制到临时区并计算 SHA-256，领域命令登记元数据，存储服务原子移动到正式目录，再由事务完成 ready。启动恢复可处理数据库回滚后的正式文件、缺失文件和摘要不一致。正式文件不可覆盖，路径、token 和中间目录重解析点均受校验。

证照续期新增版本并把旧 active 版本标记为 superseded。提醒按证照版本、到期日、阈值和类型幂等生成；到期日等于当前日即 expired。提醒仅表示软件内待办，不宣称短信或邮件已送达。

配置：`approval_levels` 为 1–3（默认 2），`reminder_days` 为 0–365（默认 30）。种子覆盖六种申请状态、多轮审批、三种文件状态、证照链和提醒确认。

验证命令：

```powershell
npm run typecheck
npm test
npm run build
```

不包含并行会签、条件分支、电子签章、OCR、在线存储或外部通知。
